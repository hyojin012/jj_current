# 진짱 — Apple-inspired minimal landing page

White-first, photo-led, realistic corporate landing page with restrained black/gray typography and subtle motion.

## One click
Double-click `START WEBSITE.bat` in the outer folder. It starts the Flask app and opens Chrome/default browser at http://127.0.0.1:5000/

## Manual
```bash
python -m pip install -r requirements.txt
python app.py
```

Then open http://127.0.0.1:5000/

## Finalization
Replace the placeholder phone number and the Unsplash demo photos with the company's actual phone number and work photography.
